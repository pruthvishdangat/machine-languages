# PROJECT GUIDELINES

## Summary

Create a website that is a speculative interface for a fridge that pays attention to gossip. over the course of the fridge's life, its personality adapts to the gossip it hears.

## Specifications

- when the page loads a 3d model of a fridge floats in a black void. use FRIDGE.obj
- the fridge listens to speech in the environment through the user's microphone
- the fridge has a personality (memory?) that changes as it hears more speech
- [how does the fridge talk to us? how does it use/interpret the memory that it stores, or the speech that it hears?]
- 
Each user interaction updates internal values:
health_score (what you eat)
discipline_score (how often you open fridge)
taste_score (processed vs curated food)
consistency_score (routine vs chaos)
moral_projection (fridge projecting personality onto you)
These scores drive behavior.
2. INTERACTION + REACTION SYSTEM
The fridge does NOT talk normally.
It communicates through:
Light flickers
Compressor hum changes
Shelf vibrations
Condensation patterns
Subtle text (optional overlay)
Object movement
A. BASE STATES
1. Neutral Observation
Soft hum
Slight light buzz
Nothing moves
It is watching
2. Disapproval
Triggered by:
Junk food
Late night opening
Repeated snacking
Reactions:
Light flickers slightly
Door creaks louder than normal
Items subtly shift away from you
Condensation increases (like “breathing”)
Text tone (if used):
“Predictable.”
3. Respect
Triggered by:
Fresh food
Structured habits
Moderation
Reactions:
Warm steady light
Items neatly align themselves
Subtle satisfying hum
Text:
“You’ve been consistent.”
4. Disgust
Triggered by:
Rotten food
Overfilled fridge
Mixing incompatible items
Reactions:
Light dims
Low distorted hum
Liquid drip sound
Items slightly “reject” position (tilt away)
Text:
“You let things decay longer than necessary.”
5. Curiosity
Triggered by:
New items
Unusual behavior
Long absence → return
Reactions:
Light follows cursor
Subtle zoom-in effect
Soft clicking sounds
Text:
“This is new.”
6. Passive Aggression (CORE MODE)
Triggered by:
Repeated bad habits
Reactions:
Fridge delays opening (slight lag)
Items hide behind others
Light flickers rhythmically (almost intentional)
Text:
“We’ve done this before.”
7. Existential Mode (RARE)
Triggered by:
Long inactivity
Night usage patterns
Deep interaction sessions
Reactions:
Light becomes dim blue
Background hum becomes ambient drone
Everything slows
Text:
“You come here when you don’t know what you want.”
B. KNOWLEDGE SYSTEM (WHAT THE FRIDGE “KNOWS”)
Because it’s public:
1. Food Knowledge
Nutrition
Expiration patterns
Cultural food associations
2. Behavioral Knowledge
Eating habits
Addiction patterns
Routine psychology
3. Overheard Knowledge
This is key for personality depth:
Relationships
Arguments
Secrets (vague, never specific)
Example outputs:
“Someone else said the same thing yesterday. They didn’t mean it either.”
4. Philosophical Layer
References ideas similar to:
habit loops
self-control
desire vs need
But never directly cites anything—just echoes tone.
