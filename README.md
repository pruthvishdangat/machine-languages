# machine-languages

This repository contains a simple static website built to accompany a philosophical manifesto. The design leans heavily on neutral, grey aesthetics to reflect the document's personality: constantly considering multiple perspectives and avoiding binary conclusions.

## Structure

- `index.html` – Home page with splash and introduction.
- `manifesto.html` – Full text of the manifesto with interactive lines that reveal alternate phrasing when clicked, reinforcing the idea of a grey area.
- `css/style.css` – Shared stylesheet defining the neutral palette, animations, and general layout.
- `manifesto.md` – Original Markdown version of the manifesto.

## Viewing

Open `index.html` in a browser to explore. The navigation bar links to the manifesto page.

## Aesthetic notes

- Grey gradients animate subtly in the background.
- Links and interactive text shift color to a softer accent when hovered.
- The overall mood is calm, contemplative, and non-committal, matching the manifesto's ethos.
